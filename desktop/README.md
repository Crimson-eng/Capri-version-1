# Capri de escritorio (Windows)

Mini Capri ronda por tu escritorio, encima de todas tus ventanas. Donde no está ella, los clics pasan a tus otras apps.

- **Tócala** para hablarle; **arrástrala** para moverla. Cuando te contesta se abre su marco con el globo de texto y después vuelve a ser estrellita.
- **⤢** abre Capri completa; el botón **MINI** la regresa al escritorio.
- Icono junto al reloj de Windows: abrir, mini, *Iniciar con Windows*, recargar, salir.

La app carga Capri desde https://crimson-eng.github.io/Capri-version-1/ (así se actualiza sola). Tu API key y la memoria se guardan dentro de la app, aparte del navegador, así que la primera vez hay que pegar la key en ⚙.

El instalador lo genera GitHub Actions (`.github/workflows/desktop.yml`). Para probar en tu PC con Node: `npm install` y `npm start` en esta carpeta.
